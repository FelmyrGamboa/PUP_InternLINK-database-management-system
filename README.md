# PUP_InternLINK-database-management-system SETUP NOTES

## How to setup the environment

- Create a virtual environment
  `python -m venv .venv`

- Enter the virtual environment created

* For Windows
  `.venv\Script\activate`
* For Linux
  `source .venv\bin\activate`

- Install all needed libraries or packages for the code using the provided requirements.txt
  `pip install -r requirements.txt`

- Run the python file to test things

## How to setup the mysql database provided

- Use the sql script provided (_pup_ilink_db_ver2.sql_)
